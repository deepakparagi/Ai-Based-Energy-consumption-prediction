## 📌 About

This project presents a state-of-the-art predictive analytics platform designed for the energy sector. By leveraging historical consumption data and sophisticated machine learning algorithms, the system accurately predicts short-term energy demand and identifies irregular consumption patterns.

Engineered with scalability in mind, it provides actionable insights through a real-time dashboard, enabling users—from residential homeowners to large-scale industrial facility managers—to optimize their energy usage, reduce operational costs, and lower their carbon footprint.

---

## ✨ Key Features

| Feature | Description |
|:---|:---|
| 🧠 **Predictive Modeling** | 24-hour power usage forecasting using Long Short-Term Memory (LSTM) and ARIMA models |
| 🔍 **Anomaly Detection** | Automated identification of irregular power spikes and drops using Random Forest isolation techniques |
| 📊 **Real-Time Dashboard** | Interactive data visualization interface for live consumption tracking and predictive insights |
| 🔌 **Appliance-Level Insights** | Granular breakdown of energy usage across specific appliances and circuits |
| 📄 **Automated Reporting** | One-click PDF report generation summarizing daily, weekly, and monthly consumption trends |
| ⚡ **Optimization Engine** | Algorithmic recommendations for load shifting and peak-demand reduction |
| 📱 **Responsive UI** | Accessible analytics across desktop, tablet, and mobile devices |

## 🚀 Getting Started

### Prerequisites

- **Python** ≥ 3.10
- **pip** (Python package installer)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/deepakparagi/Ai-Based-Energy-consumption-prediction.git

# 2. Navigate into the project
cd Ai-Based-Energy-consumption-prediction

# 3. Create a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`

# 4. Install dependencies
pip install -r requirements.txt

# 5. Run the application/dashboard
# python main.py or uvicorn main:app --reload depending on setup
```
